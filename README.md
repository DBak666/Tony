# Amaze GO — Unity 离线重建工程

使用 Unity **2022.3.62f2** 打开本目录，打开 `Assets/Scenes/Main.unity`，点击 Play。也可运行 `Builds/AmazeGO.exe`。

这是依据本机雷电模拟器中 **Amaze GO! 1.33.0** 的界面、安装包资源和关卡数据重新编写的工程。C# 是可维护的重写实现，不是原开发者源码；原游戏实际使用 Unity 6000.3.16f1。

## 已实现

- 首页、主线棋盘、胜利/失败弹窗、设置、关卡选择。
- 箭头沿自身路径向前退出，网格占位与射线阻挡判断、错误反馈和三次生命。
- 可移动箭头提示，鼠标滚轮/双指缩放、拖动平移、辅助网格、三种主题。
- 当前关卡、已消除箭头、生命值和偏好的本地保存。
- **997 个经过完整求解验证的原始关卡布局**、356 张原包界面图片。
- Windows 可运行版本；输入兼容触屏，工程设置为 Android 竖屏，但 Android 构建尚未验证。

首次进入默认显示第 5 关，用来对应本次观察到的模拟器进度。通过“选择关卡”可以从第 1 关开始。研究版的提示不收费、关卡可自由选择。

## 编辑关卡

`XSize`、`YSize` 为网格宽高。`Points` 是从箭头头部到尾部的转折点一维索引：`x = index % XSize`，`y = index / XSize`。相邻转折点必须同横行或同纵列，箭头之间不能占用同一个网格点。

```json
{"XSize":4,"YSize":5,"Arrows":[{"Points":[16,4]},{"Points":[0,1,17]},{"Points":[19,18,2]},{"Points":[3,15]}]}
```

`Solution` 是自动求解所得的箭头消除顺序，供验证使用，运行时提示会实时检查当前棋盘。编辑路径后应重新生成或更新 `Solution`。

菜单 **Amaze GO > Validate All Levels** 可检查所有导入关卡。批处理构建入口为 `ProjectBuilder.BuildWindows`。

## 还原范围

已完成离线主线玩法。原版的广告、支付、服务器、排行榜、推送，以及大逃鲨、每日挑战等活动模式没有接入。首页保留活动入口外观，并明确显示其未实现状态。

997 个关卡按 `GuideLevels1` 与 `AllLevel` 配置串接去重排列。原包包含多组实验配置，因此这一研究顺序不代表所有设备上原版的实际关卡投放顺序。

原游戏被系统通知权限弹窗挡住，尚未完成原版棋盘交互实测。碰撞逻辑已经数据验证，但坐标朝向、动画时长、三次生命及完整结算流程属于当前重建实现，需在弹窗处理后对照原游戏继续校准。

资源来自用户指定的本地安装包；中文字体为本机微软雅黑的字符子集。该工程供当前本地分析使用，资源并非本工程原创资产。存档使用独立的 `LocalStudy / Amaze GO Rebuild` 标识，不会修改模拟器内原游戏存档。

## GM 关卡工具

运行时点击首页的 **GM 关卡**，或 **设置 → GM 关卡工具**；也可以在 Game 窗口按 **F1** 打开。输入 1–997 的整数后点击“跳转并保存”，或使用上一关、下一关、重开当前关卡。实际范围随 catalog 自动更新。

切关会清除本关已消除箭头、恢复 3 点生命，并立即保存当前关卡；下次启动可继续。非法输入不会更改进度，箭头动画期间暂不接受切关。GM 仅修改本重建工程的本地存档。

## 离线活动

首页三张卡片分别进入联赛、每日挑战、大逃鲨，GM 面板新增活动调试入口。

- 联赛：本地模拟的 10 人周榜（固定模拟对手分数，不是真人服务端）；主线同一关每周首次完成 +10 分；周一结算，前三名晋级、后三名降级。有积分才发奖励，前三名 100 活动币、其他参与者 25；每次结算 1 枚奖章。
- 每日挑战：本地日期决定固定关卡，日历支持过去日期补玩、禁止未来日期；每个日期首次完成奖励 20 活动币和 1 枚奖章。
- 大逃鲨：本地五关连胜玩法，每关三点生命；失败清空本轮进度，中途退出保留棋盘；每天重置，完成后手动领取 100 活动币和 1 枚奖章，每天限领一次。
- 活动币可兑换主线生命（20 币恢复到三点），奖章用于收藏计数。

三项活动均可直接测试，不限制主线解锁等级。活动复用工程中已验证的 997 个箭头布局；规则、轮换和奖励是本地重建实现，不与原游戏账号或在线排行同步。活动单独使用 `AmazeRebuild.Activities.v1` 存档，主线仍使用原键。重开或退出活动不会覆盖主线关卡、生命和已消除箭头。

## 编辑主页 Prefab

主页资源：`Assets/Resources/UI/HomePage.prefab`。双击该资源，或使用菜单 **Amaze GO > Open Home Prefab**，进入 Prefab Mode 编辑。

- `Header`：体力显示与设置按钮。
- `Activities`：联赛、每日挑战、大逃鲨卡片；卡片内包含标题、状态底图和动态文本。
- `Title` / `Subtitle` / `Wallet`：主页标题、副标题及活动奖励计数。
- `LevelProgress`：五个关卡快捷按钮及进度线。
- `Actions`：继续、选择关卡与 GM 按钮。
- `Footer`：关卡总数说明。

可以直接调整 RectTransform、Image、Text 的位置、尺寸、图片、字号和静态文案。布局不会在运行时重新生成。根节点 `HomePageView` 中保存了按钮与文本引用；替换对象时请同步指定这些字段。动态关卡编号、活动进度、奖励数值和继续按钮文字仍由存档刷新；主题和当前关卡配色可在 HomePageView 中调整。

主页由 `AmazeGame.Home()` 加载并实例化，`HomePageView.Bind()` 仅绑定事件和更新动态内容。其他页面及公共 Canvas 暂时维持现有生成方式。主页的 Sprite 保存在 `Assets/HomeUI/Sprites`，属于真实可引用资源。

`HomePrefabBuilder.CreateAndBuild` 仅用于一次性迁移，已有 Prefab 时拒绝覆盖；没有自动重建钩子。正常编辑与构建不会覆盖你的 Prefab 修改。
