# 参考图亮面箭头风格

箭头使用程序生成的 2.5D UGUI 网格：圆角路径、深色外轮廓、侧壁、投影、亮面倒角、白色反光和少量星光。不是外部 FBX 模型，不需要额外插件或材质资源；仍兼容现有 RectMask2D、点击检测、平移、缩放与沿路径退出动画。

- `BoardView.cs`：七色调色板，每条随机选择两或三种相邻颜色，沿完整路径连续渐变；每次进入棋盘重新选色，当前棋盘刷新不重新随机。
- `CandyArrowGraphic.cs`：每条箭头独立网格，避免复杂关卡合并后超过 UGUI 顶点限制。
- `CandyBackdrop.cs`：默认主题冰蓝柔和渐变背景；网格为浅蓝凹点。
- `CandyButtonSurface.cs`：主要按钮使用亮面圆角表面，与棋盘统一。
- `AmazeGame.cs`、`HomePageView.cs`：默认冰蓝配色、冷蓝文字与按钮。旧有薄荷和深色主题仍可选。

提示状态仍是金色闪动，碰撞状态仍是红色；显示效果不改变关卡规则。参考图中的锁链和手势属于未实现机制的示意元素，本次没有将它们作为不可交互装饰覆盖到可操作棋盘。

验证：独立 Unity 2022.3.62f2 Windows 构建及隔离存档预览。检查关卡 8、25、799 的显示、消除移动、碰撞扣血、提示、缩放与复杂路径顶点数量。截图和报告保存在 QA/CandyStyle 中。
